# Next: whole-curriculum related concepts

User-requested proposal, recorded 2026-10-09. Chunk 4 closeout comes first. This feature is not yet implemented.

## Goal

Help teachers find conceptually related working tasks across Grade 3, Grade 4, Grade 5, Algebra 1/2, Algebra 1 and Algebra 2 for differentiation, extension, study guides and preview practice. Cover all 2,184 existing entries while retaining original curriculum and lesson identity. Engine owns the canonical mapping; Studio owns selection and export.

## Mapping

Review canonical providers and tag granular concepts with teacher-friendly synonyms. Distinguish same concept, supporting concepts, applications and alternative representations. Record mathematical reasons and branch/domain limits. Keep these relationships separate from reviewed difficulty and prerequisite progression; course order and keyword overlap do not establish difficulty.

Expose related connections from either endpoint without automatically reversing prerequisites. Group repeated providers and distinguish missing mapping from a concept for which no executable generator exists. Preserve all 331 Grade 5 codes and existing directions.

## Teacher interface

Provide Related Concepts alongside Difficulty/Progression. Offer this course, earlier courses, later courses and all courses, plus explicit course filters. Show coverage counts, course/lesson identity, reason for the connection and any mapping or generator gap. Preview, multiselect, add to draft, undo and mixed-course export should use the existing packet flow. Do not silently hide valid connections behind the current 100-result limit.

## Acceptance and sequence

Every working entry needs reviewed concept tags or a specific exception. Audit all six courses and both-end discovery; verify GCF/prime factorization and Pythagorean/triangle scenarios across course boundaries, preserve all existing code mappings and directions, and test teacher selection through export.

Start with vocabulary and provider inventory, then reviewed provider mappings, then the teacher interface, then complete coverage and workflow verification. Begin from the verified Chunk 4 review branches, not an older main checkout. The current Grade 5 Pythagorean entry MCADA-99.1 has some same/higher-course links but lacks the requested comprehensive lower-course related-concept coverage.
