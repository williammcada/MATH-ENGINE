# Related concepts teacher quickstart

[Download Studio v0.35.0-rc.1](https://github.com/williammcada/test-and-practice-studio/blob/9d13f0961dbb5248f4a7e35c0cf05af5b8204c4b/downloads/Test-and-Practice-Studio-v0.35.0-rc.1.html). Use Download raw file, save the HTML and open it in your browser.

1. Preview a working question and choose **Find related tasks**, or search in **Related Concepts** for GCF, prime factorization, triangles or another concept.
2. Choose **This course**, **Earlier courses**, **Later courses** or **All courses**. A specific-course filter is also available. Course order is not a difficulty rating.
3. Read the connection reason and limits. Expand other recorded connections if useful. Repeated generators are grouped; use the course/lesson selector to retain the occurrence you want.
4. Preview individual tasks or select several across pages and filters, then choose **Add selected to draft**. Clear selection affects pending choices only. Existing draft undo remains available.
5. Use the ordinary packet controls for practice, study guides, student output, keys and Word/print exports.

Use **Difficulty / Progression** for the separately reviewed easier/harder/prerequisite relationships. Concept links are broader. Course counts show mapped working matches before course filters; zero is not proof of no mathematical connection.

All 2,184 current working entries are mapped and all 331 Grade 5 standard codes are retained. The map is not an exhaustive reconstruction of every publisher item or every possible concept relationship. See RELATED-CONCEPTS-VERIFICATION.md for exact tests and limits. This download is a verified checkpoint; no hosted deployment or main-branch merge is claimed.
