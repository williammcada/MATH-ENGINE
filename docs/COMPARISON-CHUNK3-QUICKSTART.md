# Comparison Chunk 3 quickstart

Open `downloads/Test-and-Practice-Studio-v0.33.0-rc.2.html` locally in a browser.

1. Choose a course, preview a working question, and select **Find related tasks**.
2. Filter by course and connection type. **Easier/harder** means a reviewed change within a skill; **prerequisite/extension** introduces an additional construct. **Related** is not a difficulty rank.
3. Preview a suggestion, add it to the draft, or use it as the starting task to move in the other direction. Filters and previews preserve selections; Remove and Undo remain available.
4. Build a mixed-bank packet and export student pages or a teacher key. Choose a layout that fits the selected diagrams; the layout guard remains active.

To try a new comparison, find **Read a histogram interval** in Introduction to PreAlgebra (8/7), Lesson 38, item SN870341. Choose **Harder version** and **Algebra 1/2** to see a task combining two interval frequencies. Use it as the starting task and choose **Easier version** to return. Course grade alone never determines the recommendation.
