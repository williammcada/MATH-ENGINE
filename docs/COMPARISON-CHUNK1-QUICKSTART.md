# Chunk 1 Studio quickstart

Open `downloads/Test-and-Practice-Studio-v0.31.0-rc.3.html` in a modern browser. This version contains the completed number/proportional comparison review.

1. Preview a working question and choose **Find related tasks**, or choose a topic and starting task in the cross-course panel.
2. Filter by **Easier version**, **Harder version**, **Prerequisite**, **Extension** or related/similar tasks. Choose a target course if useful.
3. Preview each suggested question. The explanation describes the reviewed demand; values, required methods and answer forms can differ.
4. Choose **Add to draft** for the desired tasks. Selections stay under teacher control; remove and undo remain available.
5. Create the manual packet, then export Word or print/save as PDF. Save the draft/session to reopen the same selections and variants.
