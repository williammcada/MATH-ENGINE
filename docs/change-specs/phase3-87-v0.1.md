## Implementation scope and defaults

Studio 0.23.0-rc.1 adds packet composition to existing manual selections across all six banks. Only Engine-ready entries can be exported; reject a selection containing unresolved source previews with explicit item IDs, without removing them. Default: practice, two variants per selected task, repeatable seed, A4, one column, generous work space, optional dividers, editable title/header/instructions/footer. Permit one/two columns and Letter paper; distinguish student worksheet, teacher key and study guide. Teacher keys and study guides intentionally contain answers; student exports never do. Manual selection does not require standards or learner data.

GradeCam Student By Standard XLSX and CSV imports stay entirely local. XLSX parsing uses the actual Name/ID/GradeCam ID header and standard columns; ignore preamble and legend. Preserve identifiers as strings, source header and full standard, numeric zero, blank and hyphen states. Explicit score scale defaults to the observed 0–1 numeric proportions; percentage strings are unambiguous. Reject malformed values, duplicate columns resolving to one standard and repeated student IDs rather than guessing. Unknown/out-of-scope codes are shown for exclusion review; no guessed mapping. All 331 current Grade 5 codes/aliases resolve, without a fixed 57-column ceiling. Formula cells are rejected for score/identity inputs. No imported student data in Git or test fixtures.

Teacher selects students, included known standards, threshold (default below 70%), whether to include missing evidence (default off), items per outcome and maximum packet length. Preview explicitly displays allocations and omissions before generation. Numeric percentages are reported aggregate evidence, not mastery or recency. Keep overlapping source outcomes and warn; never silently merge scores or automatically delete teacher selections. Packet length truncation is explicit in the allocation review. Teachers may change thresholds, selection/count/cap and review again. No GradeCam account access or automated scoring-configuration claims.

Every packet uses one immutable generated question snapshot for preview, key and exports, with Engine/app/mapping versions and source IDs/seed/index in a downloadable packet session. Students never receive this teacher session file. Preserve manual draft v1/v2 import. Packet session is distinct and validated, including pinned Engine version; failed import preserves current work. No browser/cloud persistence. Visible individual/group/clear controls with confirmation and undo; downloaded files remain untouched. Warn before closing unsaved packet/import work.

Print and PDF: create paginated student-only or teacher-only output with page numbering and batch learner separation; browser Print / Save as PDF uses the inspected output, not the teacher screen. Export DOCX with editable text and native Word equations where MathML is present; diagrams as high-resolution PNGs. Match source question snapshot and answer order across outputs. Inspect actual generated PDFs and render DOCX before claiming verified Word delivery. Export failures preserve source session/packet, no rebuilding required. Standalone HTML remains self-contained, with a vendored MIT/GPL JSZip 3.10.1 dependency for XLSX/DOCX ZIP operations; no network calls or paid services.
