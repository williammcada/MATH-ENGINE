# Math Engine 0.37.0 — single-answer questions only in games

**Status:** Owner instruction, 2026-10-16 (Asia/Shanghai). Implementation checkpoint until the checks below pass on the exact committed candidate.
**Date:** 2026-10-16
**Baseline:** MATH-ENGINE `main` `9452ab4` (Engine 0.36.0-rc.1).
**Handbook:** mcada-project-handbook v0.1.12, `9d9c80f` — U-14 (the Engine owns question identities and checking; hosts own placement), U-18 (answer pad), U-04, U-06.
**Consumers:** MathQuest (pins 0.34.0-rc.3) and Math Arcade (pins 0.36.0-rc.1) receive this only when each host deliberately syncs (U-14 version record).

## Problem

MathQuest's skill preview showed an 8/7 item asking for three answers at once:

> Rename 1/3 and 1/2 using their least common denominator. Enter first numerator; second numerator; common denominator. … Separate answers with semicolons. — Answer: 2; 3; 6

Owner, 2026-10-16: "Questions that necessarily do not have a discrete single value answer need to be tagged in math engine and not delivered to math quest / math arcade."

The game index already excluded teacher-reviewed entries (decision D2, Engine 0.34.0) but had no test for answer shape.

## Design

### The tag (`src/answer-shape.js`)

A bank entry is **multi-part** when any auto-checked variant, over the same 200 build seeds used for D2, has:

1. an answer kind that is always a collection: `list`, `integer-list`, `set`, `quadratic-roots`, `domain-roots`, `leaves`, `reason-pair`, `ordered-comparison`, `divisibility`, `scientific`; or
2. answer text with `;`-separated parts; or
3. a prompt that asks for a whole collection: "give / find / list every", "list each".

The tag is per entry, not per seed. "List every positive factor of 1" is still a list question although that seed has one factor; "Find every real solution" is a solution-set question even when a seed has one root or none.

Not used as a signal: the boilerplate "separate multiple answers with semicolons", which many single-answer Algebra 2 prompts carry, and `values` arrays alone (expanded form "800000 + 3000" is one expression).

**Single answers kept:** one number, fraction, mixed number, decimal, money, time, remainder ("26 R 1"), expression, equation, inequality, prime factorization, expanded form, words. These are each one entry on the pad (U-18).

### Where the tag lives

- `curriculum/answer-shape/v0.1/answer-shape.json` — every multi-part and teacher-reviewed bank id, the rule and counts. Studio and audits can read it; Studio packets are unaffected.
- `src/practice-index.js` (generated) — the game index omits multi-part entries; `courses[].multiPartExcluded` counts them.
- Practice API (bundle):
  - `gameExclusion(id)` → `'multi-part'`, `'teacher-reviewed'` or `null`. Hosts use it to drop a saved selection that is no longer game-eligible and to tell the teacher why.
  - `gameExcludedCounts` → totals by reason.
  - `generate` / `nextItem` on an excluded id throw `Not a game item (multi-part): <id>`.
  - Runtime safety net: the bank redraw skips any multi-part variant, as it already skips teacher variants.

## Host migration (not part of this Engine change)

- **Saved selections.** `configError` rejects a selection containing an id that is no longer in the catalog ("Choose valid skills."). Before pinning 0.37.0, each host must drop saved ids for which `gameExclusion(id)` is non-null, and say so to the teacher, so a saved Math Arcade gate or MathQuest skill list does not stop working.
- **MathQuest** pins 0.34.0-rc.3. Syncing to 0.37.0 also brings the 0.36.0 answer pad, which MathQuest has not migrated to (U-18). Its sync is a separate host change spec.
- **Math Arcade** pins 0.36.0-rc.1; syncing to 0.37.0 is a direct step.
