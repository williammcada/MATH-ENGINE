# Math Engine 0.65.1 — 8/7 objective 21.6: sum of primes with 49, 51 and 57

**Status:** Requested by William McAda, 2026-10-15 (Asia/Shanghai); reapplied 2026-10-17. Implementation checkpoint; not a verified release.
**Baseline:** MATH-ENGINE `main` `17c4e3a` (Engine 0.65.0). First built as 0.35.1 (PR #7, closed unmerged 2026-10-17); reapplied unchanged to current main.

## Scope

`course-87-en:authored:MCADA-21.6`, PS.MAT.G5.OA.21.6, "Identify the sum of all prime numbers between two other given numbers" (`src/curriculum87-early.js`). The separate Algebra 1/2 item "Add primes in an interval" (`algebra-half-en:node:118`) is unchanged.

## Owner requirements

1. About 50% of items make students decide whether 49, 51 and 57 are prime.
2. No item requires identifying more than 6 primes before adding.

## Findings at the baseline

In 2,000 seeded items: none contained 49, 51 or 57 (ranges never passed 50); none exceeded 6 primes; 99 (5%) had a single prime, leaving nothing to add.

## Change

- Half the items use a range from 36–48 to 58–64, which always contains 49, 51 and 57. The other half keep the original ranges (start 1–35, width 8–15) and never contain all three.
- Every item has 2–6 primes (redrawn until true; fixed fallbacks 46–60 and 20–30).
- Numbered sets (index > 0) alternate exactly. Live game gates always request index 0, so there a seeded coin decides, giving about 50%.
- The solution for those items adds "Not prime: 49 = 7 × 7, 51 = 3 × 17, 57 = 3 × 19."
- Prompt wording, answer type and checking are unchanged.

Also `npm test` and `test:phase2` passed.
