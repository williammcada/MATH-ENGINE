## Design

Inventory every working entry across all six banks. Resolve explicit provider adaptations, retain all source, lesson and standard identities, and classify mathematical concepts using reviewed recipe contracts. Record actions, representations and answer-review requirements from executable providers. Distinguish topic membership from verified task equivalence and from a directed progression. Keep unranked tasks visible and explicitly record where no defensible harder/easier comparison is established.

Engine owns the concept map, reviewed task progressions, prerequisites/extensions, overlap evidence and recommendation API. No grade ordering or keyword score determines difficulty. Directed suggestions are permitted only for explicitly reviewed stages of the same construct, with a concrete explanation of the changed number type, representation or reasoning demand. Related topics and prerequisites are separate relations. Reused identical providers are never advertised as harder merely because they occur in a later course.

Studio adds a topic explorer and a Find related tasks action beside a working preview. Teachers can filter easier/harder/same-scope/prerequisite/extension/related tasks, inspect source course, confirmed school grade, lesson, task demand, reason and preview, then add/remove mixed-bank selections. Selecting a recommendation never silently replaces existing work. Preserve seed and variant replay, undo and clear controls. Show explicit no-link messages when a requested comparison is unavailable. Topic browsing provides access to reviewed progression anchors even where an individual task has no comparative rating.

School-grade metadata currently confirms only 8/7 as local Grade 5. Preserve that fact; show other courses by their textbook names with school grade unassigned rather than inventing G3/G4/G6/G7 mappings. Cross-bank difficulty uses task demand independently of these labels. Demonstrate a simpler perimeter task to Grade 5 irregular polygon perimeter and the reverse, without treating an identical reused provider as a harder task. Document that local grade labels for the other courses still require owner-supplied mapping.
