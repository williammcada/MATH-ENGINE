## Answer and evidence contract

Check mathematical value, requested representation and units separately. Fraction/mixed-number targets require reduced form; exponent-rule targets require the original base and correct exponent, with 1 accepted for exponent zero. Area requires square units. Return teacher-work-review requirements for LCM methods and net face calculations. A correct final answer does not claim that the required work has been performed. Automatic assignment and full-outcome verification remain false.

## Review workflow

Add `review/grade5.html`, opened from a downloaded repository or a local HTTP server. Choose a family, seed and item number, generate, enter an answer, inspect the worked solution and print the current view. Student rendering has no solution; the teacher section is closed by default and after every generation. The page stores no student information. It is an engine review utility, not the Test and Practice Studio packet workflow or Word/PDF export implementation.
