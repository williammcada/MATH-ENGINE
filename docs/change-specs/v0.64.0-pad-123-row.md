# Math Engine 0.64.0 — AM, PM, $ and % on the 123 tab (U-18 layout amendment)

**Status:** Approved by William McAda, 2026-10-16 (Asia/Shanghai): chose "Move to 123 tab" for AM/PM. Implementation checkpoint (0.64.0-rc.1) until the checks below pass on the merged commit.
**Baseline:** MATH-ENGINE `main` `54f1ff5` (Engine 0.63.0, verified release).
**Handbook:** mcada-project-handbook v0.1.14, `ca9877c`: U-18 layout amendment.

## Problem

The owner reported from the Mega Man Math port: "there's no longer AM, PM. So the time questions can't be answered."

The keys were not missing. They sat on the bottom row of the Algebra tab, and every question opens on 123. A child answering "Write half past 11 in the morning" saw digits and ":" with no AM/PM, and had no reason to look under "Algebra". `$` and `%` (money and percent answers in 8/7) had the same problem.

## Change

`src/answer-pad.js` layout only. The 40 keys and the rest of the module are unchanged.

| 123 | | | |
| --- | --- | --- | --- |
| 7 | 8 | 9 | ⌫ |
| 4 | 5 | 6 | Clear |
| 1 | 2 | 3 | / |
| 0 | . | − | R |
| : | ; | , | Space |
| **AM** | **PM** | **$** | **%** |

| Algebra | | | |
| --- | --- | --- | --- |
| x | y | ^ | ⌫ |
| + | − | × | ÷ |
| ( | ) | √ | Clear |
| = | < | > | Space |
| ≤ | ≥ | { | } |

- `keys` (the per-item key list) keeps the same 40 keys; its order follows the new layout.
- The 123 tab now has six rows and Algebra five, swapping their earlier heights. Hosts that size the pad by row count should check their layout.

Version 0.64.0-rc.1; `dist/` rebuilt with provenance.

## Unchanged

Question generation, answers, checking, IDs, `textFor`, `normalizeTyped`, `padForm`, `mountAnswerPad`'s behavior, and 123 opening first.

## Verification required

- `node tests/practice.cjs`. `answer-pad-layout` asserts the new rows. New `time-money-percent-on-123`: every time, money and percent keypad answer in a 5-seed catalog sweep can be typed with 123-tab keys alone.
- `npm test`, `npm run test:phase2`.
- Consumers (Mega Man Math v0.8, Math Arcade, MathQuest) take this layout only when they deliberately update their pinned Engine (U-14). Any test that hard-codes the old layout must be updated then.
