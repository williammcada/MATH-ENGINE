## Design and scope

Owner requested completion of roadmap step 1: broaden working question types across all six curricula, with priority to Algebra 2. This candidate adds the attached reviewed source mappings and original generators. Coverage remains source-entry coverage, not an assertion that every distinct construct in the full inventory is implemented. The rule-based inventory contains overlapping, topic-only classifications; it is not an authoritative count of distinct question types. Preserve remaining gaps explicitly in the breadth coverage report rather than declaring them covered through loose topic matches.

Implement all generators and reusable graph/clock SVG rendering in canonical Math Engine; Studio consumes a commit pin with file hashes. Original bounded variants, explicit formats and worked solutions; no execution or publication of private publisher scripts. Preserve source identity, lessons and evidence hashes. Legacy tasks may be adapted to numeric coefficient fields, constructed response or graph recognition; document these differences. Function sum/product tasks retain domain restrictions and undefined cases. Systems must be nonsingular when a unique solution is requested. Algebraic answer coefficients are ordered and exact; no unconstrained expression eval. Factoring requires actual factor constants, not polynomial roots without sign conversion. Scientific notation requires a normalized coefficient and integer exponent. Prime factorization accepts repeated prime factors or powers, never the unfactored composite. Set comparisons disregard order but reject duplicates and nonmembers. Explicit 12-hour clock input and next-day timing. Rounding is stated. SVG choices use a common scale and unique distractors, with no answer-specific styling or accessibility leaks.

Retain all 310 earlier entries, all six English banks, manual selection without standards, Introduction to PreAlgebra (8/7) display and stable IDs, seeded replay and draft import/export, key isolation, Grade 5-only differentiated-packet scope, original Mega Man baseline and separate Grade 5 provider. No student printing, Word/PDF export, release or deployment in this step.
